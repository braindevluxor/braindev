# BrainDev · Frontend

Aplicación React + Vite + TypeScript del sistema integral BrainDev.

- **Documentación:** `../docs/FRONTEND.md`
- **Configuración:** copiar `.env.example` a `.env` y completar los datos de Supabase.

```bash
npm install   # instalar dependencias
npm run dev   # desarrollo
npm run build # typecheck + build de producción
npm run lint  # lint (oxlint)
```
